# D.I.Wireless
We are using ring modulator mixers to transmit a message through magnetic fields. We use a function generator to create a 27kHz local oscillator frequency, and this LO is mixed with an audio message signal to create an amplitude modulated signal. This combined signal is used to vary the magnetic field in our transmitter coil. When the receiver coil is brought within close proximity of the transmitter coil, a magnetic field is induced within its windings which causes current to flow in the receiver coil. Sending the received signal through a ring modulator downconverts it back to the audio range. The downconverted signal then goes through a passive low pass filter and three amplifier stages before being sent into the speaker. We are using BJTs for power gain to drive the coils and op-amps to amplify the signals. All signals are generated using lab function generators. The transmitter and receiver coils are essentially an air-gapped transformer without a shared core.
